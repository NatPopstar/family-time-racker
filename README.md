# Family Time Tracker

Учёт времени, которое члены семьи тратят на работу, учёбу, дом и ребёнка,
с оценкой условной рыночной стоимости неоплачиваемого труда по лондонским ставкам.

## Как запустить

Всё работает в Docker — Node.js на компьютере для этого не нужен.

**1. Поднять базу данных** (локальный Supabase, ~12 контейнеров):

```bash
npx supabase start
```

**2. Поднять приложение:**

```bash
docker compose up -d
```

Приложение: http://localhost:5180
Админка базы (Supabase Studio): http://localhost:54433
Просмотр писем, которые шлёт система: http://localhost:54434

> Сборщик логов Supabase (контейнеры `vector` и `analytics`) отключён
> в `supabase/config.toml`. Под Windows он не работает: ходит к службе
> Docker по закрытому порту 2375 и бесконечно перезапускается. Открывать
> этот порт нельзя — это управление Docker по сети без пароля.
> Потеря: раздел логов в Studio. Всё остальное работает.

> Порты Supabase у нас нестандартные (544xx вместо привычных 543xx).
> Причина: после аварийной перезагрузки Docker служебный процесс
> `wslrelay` не отпустил порты 543xx, и PostgreSQL не мог к ним
> привязаться. Убить его нельзя — он обслуживает порты других проектов
> на этом компьютере. Порт приложения 5180 (а не 5173) занят по той же
> логике: 5173 держит проект body-tracker.

## Ежедневные команды

Запустить тесты:

```bash
docker compose run --rm app npm test
```

Проверить типы:

```bash
docker compose run --rm app npm run typecheck
```

Посмотреть логи приложения:

```bash
docker compose logs app --tail 30
```

Остановить всё:

```bash
docker compose down
```

```bash
npx supabase stop
```

> ⚠️ Обычный `supabase stop` сохраняет данные. Команда `supabase stop --no-backup`
> **удалит все записи семьи** — пользоваться ей только осознанно.


## Важные технические решения

- **Время везде хранится в минутах, целым числом.** Дробные часы при
  суммировании накапливают ошибку округления.
- **План и факт — два отдельных поля** (`planned_minutes`, `actual_minutes`)
  в одной строке. Это позволяет сравнивать намерение с реальностью.
- **Ставка «замораживается» в момент выполнения задачи** (`rate_snapshot`).
  Поэтому изменение ставок в настройках не переписывает прошлые отчёты.
- **Подкатегория без ставки (`rate_id IS NULL`) не оценивается деньгами.**
  Так работа и учёба автоматически исключены из денежного подсчёта.
- **`node_modules` живёт в томе Docker, а не на диске D:.** Диск D: внешний,
  по USB; установка пакетов на нём зависает.
